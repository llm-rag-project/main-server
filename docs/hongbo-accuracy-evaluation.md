# 홍보처 수집·선정 정확도 평가

## 평가 기준

기존 홍보처 메일 83일, 원본 기사 675건을 기준으로 다음 지표를 분리한다.

- 과거 원문 DB 보존율: 비교 대상 원문 URL이 현재 DB에 보존된 비율
- 과거 날짜 재검색률: 현재 검색 공급자가 과거 날짜를 다시 검색했을 때 원본을 찾은 비율
- 날짜 범위 후보율: 현재 업무일·발송시간 규칙 안에서 후보로 확인된 비율
- 후보 내 AI 재현율: 확보된 후보 중 과거 홍보처와 같은 URL 또는 주제를 선택한 비율
- 선택 기사 정밀도: 현재 시스템이 선택한 기사 중 과거 홍보처와 일치한 비율
- URL 정확 일치율: 정규화한 원문 URL이 동일한 비율
- 정확 일치율: URL 또는 정규화 제목이 동일한 비율
- 전체 재현율: 원본 전체 중 정확 일치와 동일 주제의 다른 대표 기사를 합한 비율

단일 평균 일치율은 수집 실패, 대표 매체 차이, AI 선정 제외를 구분하지 못하므로 사용하지 않는다.

## 현재 기준값

| 지표 | 결과 |
| --- | ---: |
| 과거 원문 DB 보존 | 675/675건, 100.0% |
| 날짜 범위 후보 확보 | 509/675건, 75.4% |
| 후보 내 AI 재현 | 402/509건, 79.0% |
| 선택 기사 정밀도 | 402/475건, 84.6% |
| URL 정확 일치 | 391/675건, 57.9% |
| URL·제목 정확 일치 | 397/675건, 58.8% |
| 동일 주제 포함 전체 재현 | 402/675건, 59.6% |

과거 원문 보존 목표 95%는 달성했다. 날짜 범위 후보율은 별도 지표이며,
과거 메일의 기사 작성일이 현재 서비스의 `이전 업무일 발송 시각 ~ 기준일 발송 시각`
범위 밖인 166건을 포함하지 않기 때문에 75.4%이다.

## 개선 전후

| 지표 | 개선 전 | 개선 후 | 변화 |
| --- | ---: | ---: | ---: |
| 동일 주제 포함 전체 재현 | 55.7% | 59.6% | +3.9%p |
| 후보 내 AI 재현 | 73.9% | 79.0% | +5.1%p |
| 선택 기사 수 | 439건 | 475건 | +36건 |

AI가 선정한 대표 기사를 백엔드 점수 정렬이 다시 밀어내던 동작을 수정했고,
동국대 소속 신호를 제목뿐 아니라 요약·카테고리에서도 판정하도록 보강했다.
서로 다른 기사를 같은 주제로 합치던 유사도 기준도 강화했다.

## 불일치 분류

- 후보 미확보 166건: DB에는 보존되어 있으나 과거 메일 날짜와 현재 날짜 범위 규칙이 달라 후보에서 제외
- AI·메일 정책 제외 80건: 후보에는 있었지만 현재 제외 기준 또는 섹션 정책으로 제외
- 선정되지 않음 27건: 후보에는 있었지만 AI 대표 기사로 선택되지 않음

카테고리별 날짜 범위 후보율은 동국대 77.8%, 대학 교육 68.5%, 불교 종단 77.5%다.
후보 내 AI 재현율은 각각 73.5%, 84.3%, 89.0%로, 현재 가장 큰 개선 대상은
동국대 법인·건학위 후보의 대표 기사 선정이다.

## 지속 개선 흐름

1. 매일 수집 시 원문·교육·종단 소스 중 하나라도 비면 최대 3회 자동 재시도한다.
2. 비교 결과에서는 수집 누락과 AI 선정 제외를 별도 원인으로 저장한다.
3. 관리자의 기사 포함·제외, 순서, 우선순위 수정은 월별 AI 인사이트에 반영한다.
4. 1·4·7·10월에는 직전 분기 행동 전체로 기준을 재조정한다.
5. 통계 화면에서 전체 및 상위 카테고리별 수집률과 일치율을 계속 비교한다.

평가 데이터는 `artifacts/hongbo_original_comparison/comparison_final.json`에 저장하며,
`scripts/compare_hongbo_original_vs_ai.py`를 다시 실행하면 현재 비교 결과로 갱신된다.
